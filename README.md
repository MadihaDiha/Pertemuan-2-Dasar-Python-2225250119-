## Cara Menjalankan Program

Pastikan **Python** sudah terpasang pada komputer.

Buka terminal pada folder utama repositori, kemudian jalankan program sesuai dengan latihan yang ingin digunakan.

### Latihan 1 – Biodata

```bash
python Latihan/01_biodata.py
```

Program digunakan untuk menampilkan data biodata mahasiswa.

### Latihan 2 – Persegi Panjang

```bash
python Latihan/02_persegi_panjang.py
```

Program digunakan untuk menghitung luas dan keliling persegi panjang.

### Latihan 3 – Konversi Suhu

```bash
python Latihan/03_konversi_suhu.py
```

Program digunakan untuk mengonversi suhu dari Celsius ke Fahrenheit dan Kelvin.

### Latihan 4 – Nilai Akhir

```bash

```

Program digunakan untuk menghitung nilai akhir berdasarkan nilai tugas, UTS, dan UAS.
